# DevProfile 🚀

A modern and responsive personal developer portfolio built with React. The portfolio showcases my skills, projects, achievements, coding profiles, resume, and contact information in a clean and interactive interface.

## 🌐 About the Project

DevProfile is my personal developer portfolio website designed to present my technical skills, projects, achievements, and professional profiles in one place.

The project currently focuses on a responsive frontend experience and is planned to evolve into a full-stack portfolio platform with backend APIs, authentication, database integration, and an admin dashboard.

## ✨ Features

- Responsive portfolio design
- Hero section with typing animation
- About section
- Categorized technical skills
- Project showcase with:
  - Project descriptions
  - Key highlights
  - Technology badges
  - GitHub repository links
- Achievements section
- Resume PDF download
- GitHub and LinkedIn profile links
- Contact form with Gmail integration
- Dark mode and light mode
- Theme preference saved using `localStorage`
- Scroll reveal animations
- Responsive mobile navigation
- Smooth scrolling
- Mobile-friendly layout

## 🛠️ Tech Stack

### Frontend

- React
- JavaScript
- HTML5
- CSS3
- Vite

### Browser APIs

- Intersection Observer API
- Local Storage API
- Gmail Compose Integration

1. Clone the Repository

2. Navigate to the Project Folder
cd DevProfile
3. Install Dependencies
npm install
4. Start the Development Server
npm run dev

The application will run on the Vite development server, usually at:
